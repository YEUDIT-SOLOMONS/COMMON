Setup for the common phone number (calls between renter and owner), Israeli VoIP number forwarded to Twilio

1. Buy an Israeli number from a VoIP provider that can forward calls over SIP.
2. Twilio console > Voice > Manage > SIP domains > Create new SIP domain.
   - Name: e.g. common-rent  (address will be common-rent.sip.twilio.com)
   - Voice configuration > "A call comes in": Webhook, POST, URL:
     https://photorental-api-826241029359.me-west1.run.app/api/calls/twilio/inbound
   - Under "IP Access Control Lists" add the provider's signalling IP addresses.
     (Without an ACL or credentials Twilio rejects the call.)
3. At the VoIP provider set forwarding of the number to the SIP address:
   sip:+972XXXXXXXXX@common-rent.sip.twilio.com  (or without the plus, per the provider's format)
   The provider must pass the caller's number in the From header (caller ID).
4. Set the number on the site:
   gcloud run services update photorental-api --region me-west1 --project rent-photo --update-env-vars Twilio__CommonNumber=+972XXXXXXXXX
5. The leg to the other party leaves from Twilio__FromPhoneNumber (the verified SIM). Until the number is set, the call button is hidden.
